Sipress

Rust　Tauri　Vue　ratatui

SIP 軟交換機的壓測工具。可以扮演民眾主動撥出，也可以扮演座席先 REGISTER 再等來電自動接聽，每 20ms 送出真實的 G.711 語音封包，並依 ITU-T G.107 估算 MOS、量測掉包率與 Jitter。同一套引擎提供桌面 GUI、終端機 TUI 與 CLI 三種介面，跑完產出 HTML 報告。

  • RFC 3261 信令，含 Digest 認證與 Session-Expires 重新協商
  • 即時顯示 ASR、CPS 與並發數

sip-fax-rs

Rust　Svelte　SQLite / PostgreSQL / MSSQL

用 Rust 從頭寫的 SIP 傳真伺服器。從 AudioCodes、Sonus 等 VoIP 閘道器接收 T.38 傳真，閘道不支援時退回 G.711。T.30、T.4/T.6 解碼到 TIFF / PDF 輸出都是純 Rust 實作，打包成單一靜態執行檔，丟上 RHEL 9/10 解壓就能跑。

  • 已用實體 AudioCodes 閘道驗證多頁 T.38 收件
  • 內建網頁管理介面，傳真可轉寄 Email、Webhook 或資料夾
  • CVE_Daily_Report

    每天早上八點從 NVD 抓前一天的 High / Critical CVE，用 Telegram 推給我。跑在 Cloudflare Workers。

  • Openvidu-record-sync

    把 OpenVidu 主節點的錄影檔同步到 CRM Gateway。Rust 寫的常駐服務。

  • mblc

    管理自己書櫃的 LINE 聊天機器人。

  • Tool-sh

    維運時累積的 Shell 小工具。
